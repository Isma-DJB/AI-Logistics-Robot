# AI-Logistics-Robot V1 Requirements

This directory contains the three preserved design drafts for Version 1:

- [Draft 0.1](specification_draft_0.1.md) — objectives, scope, requirements, and acceptance criteria.
- [Draft 0.2](specification_draft_0.2.md) — logical environment, interfaces, simulator, context, and use cases.
- [Draft 0.3](specification_draft_0.3.md) — detailed architecture, behavioral models, project structure, traceability, and final readiness review.

The diagrams referenced by these documents are stored in [`docs/architecture/diagrams`](../../architecture/diagrams/).

Drafts remain separate so that design decisions and their evolution stay traceable. Draft 0.3 is the approved baseline for starting Implementation Draft I-0.1.
