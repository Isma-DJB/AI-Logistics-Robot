# V1 Architecture

This directory contains the approved V1 architecture baseline.

- [`diagrams`](diagrams/) contains the English context, use-case, component, state, sequence, class, and project-structure diagrams.
- [`decisions.md`](decisions.md) records the architectural rules that implementation must preserve.

The detailed rationale and traceability matrix are maintained in [`Draft 0.3`](../requirements/v1/specification_draft_0.3.md).
